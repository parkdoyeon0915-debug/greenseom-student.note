# 그린섬 학생 페이지 — 통합 서버형 웹사이트

## 메뉴
- 🏠 홈
- 🎨 그림 자가진단
  - 날짜별 기록 저장
  - 그림 사진 업로드
  - 문제분석력 / 형태력 / 시험시간 내 완성도 / 표현력 / 구도 & 연출력 1~5점
  - 25점 만점 자동 계산
  - 느낀 점 / 앞으로 개선할 점 / 도연T의 한마디
  - 과거 기록 다시 보기
- 🧵 패턴 연구노트
  - 패턴별 개별 연구노트
  - 패턴 사진 1장
  - 꼭 지켜야 할 점
  - 주의해야 할 점
  - 패턴 적용 그림은 **개수 제한 없이 계속 추가 가능**
  - 셀프 피드백

업로드한 패턴 연구 노트는 01~03 항목을 1페이지, 04 항목을 2페이지로 구성하고 있었으며,
웹 버전에서도 같은 구조를 유지했습니다.
업로드한 그림 자가진단표의 5개 채점 항목과 25점 만점 구조를 반영했습니다.

## 실행
Node.js 18+ 권장

npm install
npm start

브라우저: http://localhost:3000

기본 관리자:
아이디 admin
비밀번호 change-me-now

실서비스 배포 전 아래 환경변수는 반드시 변경하세요.
ADMIN_ID
ADMIN_PASSWORD
SESSION_SECRET

데이터:
data/greenseom.db
uploads/

## 배포
Node.js 서버가 실행되는 VPS / Railway / Render / Fly.io 등에서 실행할 수 있습니다.
장기 사용 시 SQLite와 uploads를 영구 저장소에 연결하거나 PostgreSQL + S3/Supabase Storage로 교체하는 것을 권장합니다.


## 패턴 적용 그림 추가 방식
기존에 저장한 패턴을 다시 열어도 기존 그림은 삭제되지 않습니다.
`+` 사진 선택에서 새 그림을 여러 장 선택하면 기존 그림 뒤에 계속 추가됩니다.
